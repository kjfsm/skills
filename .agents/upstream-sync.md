## 差分の測り方 — 行単位で数えない

本家は em-dash(`—`)を `:` や `,` に置き換える **文体スイープ** を繰り返している。日本語のこのフォークには1行も当たらないのに、行単位の diff ではこれが変更の過半を占め、実質変更が埋もれる。

```
scripts/upstream-diff.py <本家のクローン先> <base> <head>
```

句読点だけの差を落とし、実質変更のあったファイルと、片側にしか無いファイルを出す。**行単位でペアリングしないこと** — 段落の折り返しが変わっただけで「追加」と数えられ、誤検知だらけになる。スクリプトは段落単位で正規化してから比較する。

## どこまで取り込んだか

**上の表の範囲は、実質変更をすべて確認済みである。** 次節に挙がっていないものは、反映したか、こちらに存在しないスキルへの変更のどちらかである。

つまり次節は **除外リストであって、取り込みリストではない**。次に同期する人は、迷った変更がそこに載っていなければ「反映済み」と読んでよい。個々の取り込みをなぜそうしたかは、それを行ったコミットにある(PR #29、#30)。
