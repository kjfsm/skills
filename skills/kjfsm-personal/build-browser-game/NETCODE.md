# 部屋の DO と画面の通信

partyserver そのものの挙動は `/kjfsm-skills:partyserver-on-durable-objects` が持つ。ここに置くのは、その上で部屋と画面をつなぐときに踏みやすいものである。ログインを入れるなら、Worker から DO へ誰かを渡す部分が増える(→ [ACCOUNT.md](ACCOUNT.md))。

## サーバー

- **部屋の DO はハイバネーションさせない**(`static options = { hibernate: false }`)。`setInterval` の時計が回っている間はどのみち眠れず、眠らせる設定は起き直したときの組み直しを増やすだけである。人がいなくなったら `clearInterval` して状態を捨てる
- **何も届かないまま 10 秒たった接続は閉じる。** StrictMode や開発サーバーの読み込み直しで張りかけのまま捨てられた WebSocket は、close が DO に届かず、部屋に幽霊として残る。入力の無い放置の人は、これとは別に 150 秒で閉じる
- **Free の DO は、受けたメッセージ 20 通を1要求に数える**(送るのは無料)。入力は量子化して変わったときだけ送り(最大 20Hz)、1秒あたりの受信数に上限を置く。状態は 30Hz で全員へ配ってよい
- **公開の部屋は `getByName(name, { locationHint: "apac" })` で取る。** DO は最初に入った人の近くに作られて以後動かないので、日本の近くに固定する。本番の往復は十数 ms に収まる
- **WebSocket の経路は `/api/*` の下に置き、`src/worker/index.ts` の Hono から DO へ渡す。** テンプレートの `wrangler.json` は `assets.run_worker_first` で `/api/*` だけを Worker へ向けていて、それ以外の経路にはアセットに無い要求でも画面の `index.html` が返る。partyserver の既定の経路(`/parties/…`)を `run_worker_first` に足さないのは、画面の要求で Worker を起こさないためにそれを `/api/*` だけに保っているからである(テンプレートの `docs/adr/0001`)。partyserver の側は `prefix` で経路を合わせる
- **入力の検証(zod)は `src/worker/` の側に置く。** 画面と共有する protocol のファイルに置くと画面の束に入る。外すだけで、束が 34KB から 14KB(gzip)に減った例がある
- **welcome に配線の版(`PROTOCOL_VERSION`)を載せ、版が違えば画面に読み込み直しを促す。** デプロイで DO が置き直されると、開いたままのタブが古い JS のまま自動で繋ぎ直してくる
- **DO のクラスは Worker の入口(`src/worker/index.ts`)から export する。** テストの Worker(`vitest.config.ts` の `main`)も `wrangler.json` の DO 束縛を読むので、入口にクラスが無いと起動しない

## 画面

- **自分のキャラは手元で先に動かす。** 式はサーバーと同じ関数を使い、状態が届くたびに「サーバーの位置 + 速度 × (往復 + 半 tick)」へ少しずつ寄せる。ぶつけられて速度の差が大きいときだけ、サーバーの速度をすぐ受け入れる。他人とは手元で跳ね返さず、重ならないよう押し離すだけにする。跳ね返すと、サーバーの結果と二重に弾かれる
- **他人は 80ms 遅れで、2つの状態の間を補間する。** サーバーの時計は、いちばん早く届いた状態に合わせる。tick が巻き戻ったら(新しい部屋に移ったら)、時計ごと捨てる
- **場が縮むなら、カメラはその勝負の始まりの大きさに固定する。** 縮む大きさに合わせて拡大すると、縮んでいることが見えず、キャラが大きくなっていくように見える。場の大きさが勝負ごとに変わるなら、勝負の合間にだけなめらかに寄せる
- **画面が出し続ける値は、出来事ではなく状態に載せる。** 場の始まりの大きさや優勝者を、決着の出来事や手元で見た最大値から組み立てると、途中から入った人と、裏のタブから戻って古い出来事を捨てた人に届かない。縮んだ場に寄った画や、優勝の出ない結果の画面になる
- **canvas に 1px 未満のフォントを頼まない。** 盤面の単位(キャラの半径が 1)のまま文字を描くと、最小の文字サイズに丸めるブラウザがある。画面の px に戻してから描く
- **演出(衝突・脱落・決着)は、描く時刻に合わせて鳴らす。** 溜めた出来事は welcome で捨て、1 秒より古いものも捨てる。捨てないと、裏のタブから戻ったときに溜まった演出が一度に鳴り、前の部屋の出来事が新しい部屋の時刻で鳴る
- **接続は `setTimeout(0)` で1拍おいてから張る。** StrictMode は画面を作ってすぐ壊し、作り直す。1拍おかないと、張りかけの接続がもう1本できて幽霊になる
- **ping は `setInterval` で送る。** `requestAnimationFrame` に載せると裏のタブで止まり、サーバーの 10 秒の掃除に切られる
- **画面が読む依存は、開発サーバーの `optimizeDeps.include` に並べる。** 開発サーバーは初めて見た依存を事前バンドルし直してページごと読み込み直すので、これも幽霊の元になる

## スマホの実機

- **音は pointerdown だけでなく、pointerup・click・keydown でも解禁を試す。** iOS の Safari は pointerdown を利用者の操作に数えない
- **Wake Lock は start で取り、表に戻るたびに取り直す。** destroy のあとに解決した lock は release する
- **プレイヤー名などの localStorage は `useSyncExternalStore` で読む。** 別のタブで名前を変えたときの `storage` イベントも同じ購読で拾え、描画中に直接読む書き方より古い値が残らない
