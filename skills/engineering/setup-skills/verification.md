# 検証ゲート

`/verification-loop` がこのリポジトリで走らせるコマンド。上から順に走らせ、最後にすべてを中断なく1回で通す(**クリーンラン**)。

| ゲート     | コマンド         | 備考                            |
| ---------- | ---------------- | ------------------------------- |
| 型チェック | `pnpm typecheck` |                                 |
| lint       | `pnpm lint`      |                                 |
| テスト     | `pnpm test`      |                                 |
| ビルド     | `pnpm build`     |                                 |
| 観測       | 下記             | 変更した経路を実際に1度駆動する |

## 観測

このアプリをどう起動し、変更を自分の目でどう確かめるか — 開発サーバーの起動コマンドと叩く URL、Playwright スクリプト、CLI の呼び出しなど。

取得した証拠(レスポンス本文、stdout、スクリーンショット)を貼れる形で書く。駆動できるものが何もないリポジトリでは、その理由を1行書く。

## カスタムチェック

汎用のリンターが見逃す、このリポジトリ固有のルール。それぞれ **決定的に実行できる形** — コマンド、grep、テスト — で書く。判断が要るものはここではなく、リポジトリのコーディング標準に置く(`/code-review` の Standards 軸が読む)。

- (なし — 手作業で捕まえた不具合が出てきたら、`/verification-loop` のラチェットがここに書き足す)
