# 状況で開くもの

[`SKILL.md`](SKILL.md) が持つのは **起点** — 作業を始めるときにどのフローへ入るか。この文書が持つのは、そのフローを走っている最中に **状況が満たされたときだけ** 入るもので、どれも起点にはならない。

## テストの土台が無い、信用できない

`/tdd` はテストを書ける土台を前提にする。Cloudflare Workers でそれが揃っていないなら先に通す。

- **`/create-tests`** — テストが1本も無い
- **`/rebuild-tests`** — 既存スイートが遅い・OOM する・`vi.mock` だらけ
- **`/react-router-worker-tests`** — SSR を `main` に載せて1ファイル十数秒かかる

## スタック固有の規律

`/implement` と `/tdd` の下敷きになる。呼び出さなくてよい — そのリポジトリのコードを書くときにモデルが自分で手を伸ばす。

- **`/react-router-route-module`**(React Router framework mode)— 認可の強制点は `middleware`、レイアウトが持つ値は `<Outlet context>`
- **`/drizzle-generate-non-interactive`** — TTY を求めるのは rename の判定だけ
- **`/migrate-d1`** — 再構築の生成物は D1 で子表を空にする
- **`/squash-d1-migrations`** — マイグレーションを1本に畳む

## ロジックを変えない機械的な変更

ディレクトリ再編、大量リネーム、import の一括付け替え → **`/ai-efficiency`**。1ファイルずつ Read/Edit せず、シェルで一括処理して抜けは typecheck で拾う。

## マージやリベースがコンフリクトで止まった

**`/resolving-merge-conflicts`**。ハンクごとに双方の意図を一次情報源までたどってから解決し、操作を完了させる — `--abort` で逃げない。フローのどこからでも入る、作業を止める割り込み。

## スレッドが埋まった、枝分かれしたい

- **`/handoff`** — 会話をマークダウンへ圧縮し、**新しいセッションを開いてそのファイルを参照する**。どちら向きにも使える。
- **`/compact`**(組み込み)— **同じ会話に留まり**、それより前のやり取りを要約させる。逐語的な履歴を失って構わない **フェーズ間の区切り** で使う — 途中で挟むと道を見失う。

`/handoff` は分岐し、`/compact` は続行する。

## プロセスではなく言葉が問題になった

他のスキルの _下敷きとして_ 動く4つのモデル呼び出し型リファレンス。それぞれがその語彙の唯一の情報源。

- **`/domain-modeling`** — _ドメイン_ の語彙。曖昧な用語に異議を唱え、多義語("account" が3つの役割を兼ねる)を解消し、後戻りしにくい決定を ADR に記録する。`/grill-with-docs` が `CONTEXT.md` を用語集に保つために駆動する。
- **`/codebase-design`** — モジュールの _形_ の語彙(深さ、シーム、アダプター、レバレッジ、局所性)。小さなインターフェースの裏に振る舞いを隠す。`/tdd` と `/improve-codebase-architecture` が使う。
- **`/delegation`** — 作業を _どこで_ 走らせるかの語彙(押し出し、階層、報告の長さ)。読み返さない大量出力は子コンテキストへ、探索は下位モデル、設計判断は上位モデルへ。スマートゾーンが1つのコンテキストをどこまで伸ばせるかなら、これは何をそこに入れずに済ませるか。サブエージェントを起動するスキル(`/two-axis-review`、`/improve-codebase-architecture`、`/wayfinder`)が使う。
- **`/where-to-write-what`** — 情報の _宛先_ の語彙(コードには How、テストには What、コミットログには Why、コメントには Why not。JSDoc・PR 本文・ADR・docs はここから派生する)。同じ事実は1か所にだけ書く。`/implement` がコミット前に呼ぶ。
