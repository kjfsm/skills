# マージコンフリクトの解決

1. マージ/リベースの **現在の状態を確認する**。git の履歴と、コンフリクトしているファイルを確認する。

2. 各コンフリクトの **一次情報源を見つける**。各変更がなぜ行われたのか、元の意図は何だったのかを深く理解する。コミットメッセージを読み、PR を確認し、元のイシュー/チケットを確認する。

3. **各ハンクを解決する。** 可能な限り両方の意図を保持する。両立しない場合は、マージが掲げる目標に合う方を選び、そのトレードオフを書き留める。新しい振る舞いを作り出しては **ならない**。常に解決すること。`--abort` は決して使わない。

4. **`/verification-loop`** でクリーンランを取る。マージによって壊れたものを直す。

5. **マージ/リベースを完了させる。** すべてをステージしてコミットする。リベース中の場合は、すべてのコミットがリベースされるまでリベース処理を続ける。
