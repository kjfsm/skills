# 弾く層を敷く

`AGENTS.md` と `.claude/rules/` は読まれれば効くが、読まれたかは観測できない。機構はハーネスや git が実行するので、**モデルが何を読んだかと無関係に効く**。`/kjfsm-skills:setup-rules` の自己更新ルールの3段目(1. パス固有の事実は rules、2. 手順は skills、**3. 決定的に弾きたい挙動はここ**)に当たる。

探索し、提示し、確認してから書く。**機構は Claude Code のフックのことではない。3層ある。**

## 層は「何から見えるか」で決まる

1つの検査が置ける層は、たいてい1つしかない。

| 層                                                | 届く相手                                     | 構造的に見えないもの                                                            |
| ------------------------------------------------- | -------------------------------------------- | ------------------------------------------------------------------------------- |
| `.claude/settings.json` の `permissions.deny`     | Claude が**名指ししたパス**(Bash の中も含む) | **名指ししない読み書き**(`grep -r`、`pnpm install` による lock の書き換え)      |
| `scripts/check-*.ts` ← git hook + CI + 検証ゲート | 人間・モデル・手元・クローン・CI のすべて    | **gitignore 済みのファイル** — staged にならないので git からは原理的に見えない |
| `.claude/hooks/*.sh`(Claude Code のフック)        | そのマシンの Claude セッションだけ           | クローンにも CI にも人間にも届かない                                            |

**上から順に試す。** 下ほど効く範囲が狭く、書く量が多く、**壊れても誰も気づかない**。3層目に残ってよいのは、上2つから構造的に見えないものだけである。

- **コマンドの形でしか判定できない書き込み** — 引数にパスが出てこないもの(`pnpm install` による lock の書き換え)
- **git hook 自身を飛ばすフラグ**(`--no-verify`)— git hook に入れるのは自己言及で、原理的に不可能
- **モデルへの働きかけ** — 促し、注意の喚起。git hook はモデルに話しかけられない

これ以外が3層目に残っているなら移し損ねである。**「フックだけが持っている検査」は、クローンでも CI でも効いていない。**

## 何を機構にするか

**4つすべてを満たすものだけ**を落とす。1つでも欠けたら散文のままにする。

1. **すでに散文で書いてあり、実際に破られた。** 破られていないルールに機構を足すと、コストだけが残る
2. **破られたことに気づけない、または戻すのが高い。** 型エラーや落ちるテストが教えてくれるものには要らない — 生成物の手編集(次の再生成で黙って消える)、シークレットのコミット、適用済みマイグレーションの改変が典型
3. **ツールの入力かリポジトリの状態だけで機械的に判定できる。** パスの glob、コマンドの接頭辞、`git diff` の結果。**「適切か」の判断が要るなら機構にはできない**
4. **実態を数えた。** 「規約に書いてある」は根拠にならない。`git log --first-parent` で PR 経由率を数え、`git log -p` で手編集の痕跡を探す。規約と実態が食い違うなら、**先に決めるのはどちらが正かであって、機構ではない**

**通ってよい操作を1つでも止める検査は、無いより悪い。** 止められたモデルは目的を捨てず別の経路を探す — 生成し直すコマンドが書いていなければ、生成物を消してから同名で書き直す。ルールは守られたように見えて緩む。

⚠️ **回避手順がドキュメントに書かれていたら、その検査は厳しすぎる。** 「`rm` してから同名で `Write` する」のような行は、述語を直す合図である。

## 手順

### 1. 探索する

- `AGENTS.md` / `.claude/rules/` — **すでに書いてある**禁止事項。ここに無いものはまだ候補ではない
- `git log` — 実際に破られた痕跡と条件4の数。生成物の手編集を戻すコミット、revert
- `.gitignore` と生成物の実パス、それぞれの再生成コマンド
- `lefthook.yml` / `.husky/` / `package.json` の `simple-git-hooks` — git hook の層がすでにあるか
- `.claude/settings.json` — 既存の `permissions` と `hooks`。あるならマージする
- `.github/workflows/` と `docs/agents/verification.md` — 同じ述語がすでに CI 側にあるか
- git の破壊的コマンドだけが目的なら、本家の `git-guardrails-claude-code`(`npx skills add mattpocock/skills --skill git-guardrails-claude-code`)が完成品を持っている

**既存のフックを1本ずつ、何が見えているかで数え直す。** CI にも検証ゲートにも同じ述語が無いフックは、手元の Claude セッションの中でしか効いていない。それが意図どおりかを、移す前に確かめる。

### 2. 候補を挙げ、層を割り当て、確認する

候補ごとに4条件と**行き先の層**を1行ずつ埋める。埋まらないものは落とす。一覧をユーザーに見せ、確認を取ってから書く。

層は上の表で機械的に決まる。「どちらからも見える」ときだけ、**広いほう**(表で下の行)を採る。

### 3. 割り当てた層の節を読んで書く

割り当てがあった層の節だけを [recipes.md](./recipes.md) で読み、雛形とそこに並ぶ規律に従って書く。settings.json への書き込み(JSON の形、既存の設定とのマージ)は組み込みの `update-config` スキルに任せる。

- `permissions.deny` → §1。パスの保護はここで終わる
- 検査スクリプト → §2
- Claude Code のフック → §3 と、目的に合う §4〜6、配線は §7

### 4. 両方向を検査する

**弾く入力・通す入力・誤爆しそうな入力**の3種類で試す。通す側が壊れている検査は、動いて見えて作業を止める。やり方は [recipes.md](./recipes.md) の §8。

### 5. 置き場所と越えない線

- **`.claude/settings.json`** — コミットする。clone した全員とクラウドセッションに届く
- **`.claude/settings.local.json`** — 手元だけ。gitignore 済み。端末固有のパスを含むフックはこちら
- **`~/.claude/settings.json`** — 全プロジェクト。置けるのは**実行時にスコープを決める**ものだけで、1本のフックの中でそのリポジトリを見て、該当しなければ黙って通す(`lefthook.yml` が無いリポジトリで `--no-verify` を止めても雑音でしかない)

⚠️ **フックはユーザーの権限で走る。** プロジェクトの `.claude/settings.json` のフックは、そのフォルダを信頼する前に走りうる。リモートから取ってきたものを実行しない、シークレットを読まない、書き込みをしない。

### 6. 散文側を追随させる

**層を移したら、その検査を名指ししている散文を全部辿る** — `AGENTS.md`、`.claude/rules/`、`docs/agents/verification.md`、`docs/`、各スキル。

⚠️ **名前を置換するだけにしない。** 「フックが弾く」を「`permissions.deny` が弾く」に置き換えると、旧フックの時代から嘘だった主張が生き残る(`permissions.deny` はパスを名指ししない書き込みを見ないが、置換された散文はそこまで守られると書いていた)。書き直すのは名前ではなく、**その層で本当に何が止まるか**である。

機構にしたルールは、散文側では「何が弾くか」の1行に痩せさせる。両方に書くと、機構が黙って壊れた日に散文だけが残り、守られていると誤解したまま進む。

### 7. 完了

置いたものと、**それぞれが何を通すか**を層ごとに伝える。散文側で痩せさせた行と、移した結果クローンと CI にも効くようになった検査にも触れる。
