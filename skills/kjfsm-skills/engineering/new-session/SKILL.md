# 新しいセッションを立てる

コマンドを提示して終わりにしない。立てるのは `session-launcher` サブエージェントである — 状態の引き方や画面の読み方は、このコンテキストに持ち込む価値が無い。

## 1. 決める

- **名前** — 言われていなければ、これから何をするかから短く付ける。`-w` で作るならブランチが `worktree-<名前>` になり、`claude agents` の一覧にもこの名前で出るので、自動生成の名前より後で読める。同じ名前で打ち直すと既存の worktree を開き直すので、連番を振らない
- **最初の入力** — あれば。立てたあとに打たせず、起動時の引数で渡す。あとから足すと、それまでに相手が動き出している
- **続きなら** `--resume` の ID
- **既存の worktree で立てるなら** そのパス — Stack の層のように、既定ブランチ以外から生やした worktree を立てる側が用意したとき。渡さなければ `-w` で新しく作る

## 2. 立てさせる

`session-launcher` に、決めた名前・最初の入力・ID・worktree のパスだけを渡す。手順と報告の形はエージェントが持つので、ここに書き足さない。

## 3. 返ってきたものを伝える

状態と、最初の入力が全文届いたかをそのままユーザーに伝える。**止まっているなら、代わりに答えない** — 何で止まっているかと `claude attach <id>` の行を渡し、人間に任せる。`claude agents` の一覧から選んで入ってもよい。

初回のディレクトリが信頼ダイアログで止まるのは、立てる側で先に通しておく話である。`-w` の worktree は origin の既定ブランチから生え、gitignore されたファイルは `.worktreeinclude` に書いた分しか入らない。

止めるのは `claude stop <id>`(worktree ごと消すなら `claude rm <id>`)である。バックグラウンドセッションはプロセスを `kill` してもデーモンが立て直す。

完了基準: セッションが立ち、「動いている」か「何で止まっている」か、最初の入力が全文届いたかをユーザーに伝え、`claude attach <id>` の行を渡した。
