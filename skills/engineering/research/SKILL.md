# リサーチ

**バックグラウンドエージェント** を立ち上げてリサーチを行わせ、それが読んでいる間も作業を続けられるようにする。読み込みの量とモデル階層の選び方は `/delegation` に従う。ユーザーが引数を渡した場合は、それが調査対象の問いである。

その役目:

1. **一次情報源** — 公式ドキュメント、ソースコード、仕様、ファーストパーティの API — に対してその問いを調査する。それらの二次的な要約ではない。すべての主張を、それを裏付ける情報源までたどる。
2. その発見を1つのマークダウンファイルに書き、各主張の出典を引用する。**長さは問いが必要とする分に合わせる** — 実質を網羅し、埋め草の節・重複した要約・定型句で膨らませない。
3. リポジトリがすでにそうしたメモを保管している場所に保存する。既存の慣習に合わせ、それがなければ適切な場所に置き、どこに置いたかを伝える。
