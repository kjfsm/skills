# トリアージラベル

これらのスキルは5つの正規のトリアージロールで語る。このファイルは、それらのロールをこのリポジトリのイシュートラッカーで実際に使われるラベル文字列に対応付ける。

| kjfsm/skills でのラベル | このトラッカーでのラベル | 意味                                           |
| ----------------------- | ------------------------ | ---------------------------------------------- |
| `needs-triage`          | `needs-triage`           | メンテナーがこのイシューを評価する必要がある   |
| `needs-info`            | `needs-info`             | 報告者からの追加情報待ち                       |
| `ready-for-agent`       | `ready-for-agent`        | 仕様が固まっており、AFK エージェントの着手待ち |
| `ready-for-human`       | `ready-for-human`        | 人間による実装が必要                           |
| `wontfix`               | `wontfix`                | 対応しない                                     |

スキルがあるロールに言及するとき(例:「AFK-ready のトリアージラベルを適用する」)は、この表に対応するラベル文字列を使う。

右側の列は、実際に使っている語彙に合わせて編集する。
