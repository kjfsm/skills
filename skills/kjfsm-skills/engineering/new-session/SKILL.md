# 新しいセッションを立てる

コマンドを提示して終わりにしない。立てるのは `session-launcher` サブエージェントである — pty の与え方や tmux の読み方は、このコンテキストに持ち込む価値が無い。

## 1. 決める

- **名前** — 言われていなければ、これから何をするかから短く付ける。ブランチが `worktree-<名前>` になるので、自動生成の名前より後で読める。同じ名前で打ち直すと既存を開き直すので、連番を振らない
- **最初の入力** — あれば。立てたあとに打たせず、起動時の引数で渡す。あとから足すと、それまでに相手が動き出している
- **続きなら** `--resume` の ID

## 2. 立てさせる

`session-launcher` に、決めた名前・最初の入力・ID だけを渡す。端末が iTerm2 のときはそう伝える。手順と報告の形はエージェントが持つので、ここに書き足さない。

## 3. 返ってきたものを伝える

状態をそのままユーザーに伝える。**止まっているなら、代わりに答えない** — 何で止まっているかと `tmux attach` の行を渡し、人間に任せる。

初回のディレクトリが信頼ダイアログで止まるのは、立てる側で先に通しておく話である。worktree は origin の既定ブランチから生え、gitignore されたファイルは `.worktreeinclude` に書いた分しか入らない。

完了基準: セッションが立ち、「入力欄が出ている」か「何で止まっている」かをユーザーに伝え、`tmux attach` の行を渡した。
