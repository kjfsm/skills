## 1. ひとりで CPU と1勝負できる

勝負の計算・部屋の DO・canvas の画面・スマホの操作を、細く一本通す。

- **勝負は、DO にも画面にも依らないクラスに入れる。** 乱数は種つきのものを外から渡し、時刻は tick の数から作る。node 層のテストで、勝負を種から再現する
- **動きの式と数は、それぞれ1か所に置く。** 加速・衝突・突進の式はサーバーと手元の予測が同じ関数を呼び、数は定数のファイルにまとめる。2か所に書くと両者がずれ、手元の補正が止まらない
- **決着は、残りが1つになった瞬間に決める。** 脱落しきるのを待ってから数えると、相手を落とした勢いで自分も落ちた側が引き分けになり、先に落ちた側に手柄がつく。手柄は、そのときまだ場に残っている相手にだけつける
- **途中で抜けた人も、負けとして結果に載せる。** 抜ければ負けが消える形だと、負けそうになったら抜ければよくなる。勝ちが決まったあとに勝者が抜けたなら、勝ちのまま記録する
- **勝ち数は先取で一区切りにする。** 先取した人が出たら、その勝負の結果をふだんより長く見せて優勝を告げ、全員の勝ち数を 0 に戻して次へ進む。公開の部屋は人の出入りが続くので、誰かの「もう一回」を待たない
- **部屋1つを DO 1つにする。** 人がいる間だけ固定の tick で勝負を進め、全員へ配る(→ [NETCODE.md](NETCODE.md) の「サーバー」)
- **スマホの操作は左右で分ける。** 左半分は触れた位置を中心にしたスティック、右半分はどこを叩いてもボタンにし、`touch-action: none` と safe-area を入れる

観測を `docs/agents/verification.md` の観測の行に書く。以後のチケットでは `/kjfsm-skills:verification-loop` がこれを駆動する。Playwright のスクリプトで iPhone の縦・横と PC の3台を同じ部屋に入れ、スクリーンショットで次の3つを見る。タッチは CDP の `Input.dispatchTouchEvent` で入れる。スクリーンショットに出る `caret-color` のハイドレーション差分は、Playwright がカーソルを隠すスタイルなので無視してよい。

- 右上の人数が人の数と合うか。合わなければ幽霊が居る(→ NETCODE.md)
- HUD が盤面やボタンに重ならないか。iPhone SE の縦と、横持ちの低い画面も見る
- 開始・脱落・決着・優勝・次の勝負までが一巡するか

完了: 勝ち・引き分け・手柄・途中で抜けた人・優勝と勝ち数の戻りを、種つきのテストで1本ずつ確かめた。bindings 層で DO に WebSocket を張り、welcome・顔ぶれ・状態が届くことを確かめた。

## 2. 数をシミュレーションで決める

CPU 同士の勝負を数百回回すスクリプト(例: `pnpm sim`)を置き、勝負の長さ・最初の脱落までの時間・一区切りの長さを測る。**勝負の長さだけを見ない。** 平均 16 秒でまずまずに見えた勝負で、最初の脱落が平均 4 秒弱、早い回は 2 秒を切っていたことがある。人間が自分のキャラを見つける前に終わる。反発と突進を軽くして抵抗を上げ、出だしの 1.5〜3 秒は CPU に様子見させると直る。

人間が全員抜けたら CPU 同士を早回しする、といった仕組みはシミュレーションでは切る。コンストラクタで倍率を渡せば、共有の定数を書き換えずに済む。

**数から導いて画面に出すもの(推奨レベル・「手ごわい」のような警告・見込み)も、測った進み方に合わせ直す。** 数だけ直すと、表示が想定した進み方から遠ざける向きに働く。レベルの伸びを遅くしたあと、推奨レベルが実際に入るレベルより 5〜7 高く出て、ボットがレベル1のまま踏破する階層に警告が出ていたことがある。初めて遊ぶ人が最初の手応え(最初のレベルアップなど)を得るまでの時間も測る。進み方の全体だけを合わせたら、最初のレベルアップまで放置で1時間かかっていた。

完了: 3つの分布を出した。数を変えたら回すことを、そのリポジトリの `.claude/rules/` に書いた。

## 3. 手触り

自分のキャラは手元で先に動かし、他人は補間して描く。カメラと文字の描き方、演出と音を鳴らす時刻も含めて、[NETCODE.md](NETCODE.md) の「画面」と「スマホの実機」に沿って作る。

完了: 観測で、縦・横・PC の3台が同じ部屋で遊べる。場が縮むゲームなら、縮む間もキャラの大きさが変わらずに見える。

## 4. 公開の部屋と合言葉の部屋

- **公開の部屋は、満員なら次の部屋へ回す。** `locationHint` で日本の近くに置く
- **合言葉の部屋では、CPU を外して1対1ができる。** 外しても人がひとりなら、CPU を1体だけ呼ぶ
- **プレイヤー名は端末(localStorage)に持ち、設定画面で変えられるようにする。** 入力欄は `autoComplete="off"` にする。`name="name"` の欄には、ブラウザが本名の自動入力を差し出す

完了: 満員で断ることを、bindings 層でテストした。
