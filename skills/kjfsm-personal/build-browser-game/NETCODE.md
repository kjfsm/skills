# 通信まわりで踏んだもの

もちずもう(`~/github/kjfsm/game-01`)で、部屋の DO と画面をつなぐときに踏んだものを置く。partyserver そのものの挙動は `/kjfsm-skills:partyserver-on-durable-objects` を見る。

## サーバー(Durable Object)

### 時計と生存

- **ハイバネーションさせない**(`static options = { hibernate: false }`)。`setInterval` の時計が回っている間はどのみち眠れない。眠らせる設定にしても、起き直したときに状態を組み直す手間が増えるだけである。人がいなくなったら `clearInterval` して状態を捨てる
- **10 秒何も届かない接続は閉じる。** StrictMode や開発サーバーの読み込み直しで、張りかけのまま捨てられた WebSocket がある。その close は DO に届かず、部屋に幽霊として残る。入力の無い放置の人は、これとは別に 150 秒で閉じる
- **ping は手元の `setInterval` で送る。** `requestAnimationFrame` に載せると、裏のタブで止まる。止まると、上の 10 秒の掃除に切られる

### 課金と置き場所

- **Free の DO は、受信メッセージ 20 通を1要求として数える。** 送信は無料である。そこで次の形にする
  - 入力は量子化して、変わったときだけ送る(最大 20Hz)
  - 状態は 30Hz で全員へ配る
  - 1秒あたりの受信数に上限を置く
- **公開の部屋は `getByName(name, { locationHint: "apac" })` で取る。** DO は最初に入った人の近くに作られ、以後動かない。日本の近くに固定すると、本番の往復は 16〜18 ms だった

### 入口(Worker)

- **ログインは Worker が確かめ、ヘッダで DO へ渡す。** ブラウザから届いた同名のヘッダは Worker で消す。Origin を見て、他のサイトから張られた upgrade を断る
- **WebSocket の経路は、`workers/app.ts` の「本体を読み捨てる行」より前で返る。** そのため GET 以外の要求は、本体を読み捨ててから 405 を返す(テンプレートの `routes.md` の ⚠️ の件)
- **同じ userId の入り直しでは、古い接続を閉じる。** 閉じるのは、部屋の状態を手に取る**前**。古い接続が最後の1人だと、抜けた時点で状態を捨てる処理が走り、手に取った状態が宙に浮く

### 配線

- **入力の検証(zod)は `.server.ts` に置く。** 共有の protocol に置くと画面の束に入る。もちずもうでは、外しただけで 34KB → 14KB(gzip)になった
- **welcome に配線の版(`PROTOCOL_VERSION`)を載せる。** 版が違えば、画面に読み込み直しを促す。デプロイで DO が置き直されると、開いたままのタブが古い JS のまま自動で繋ぎ直してくる
- **bindings 層のテストでは、`tests/bindings/worker.ts` から DO のクラスを export する。** テストの Worker は `wrangler.jsonc` の DO 束縛を読むので、クラスが無いと起動しない

## 画面

### 予測と補間

- **自分のキャラは手元で先に動かす。** 式はサーバーと同じ `physics.ts`。状態が届くたびに、`サーバーの位置 + 速度 × (往復 + 半 tick)` へ少しずつ寄せる
  - 速度の差が大きいとき(ぶつけられたとき)だけ、サーバーの速度をすぐ受け入れる
  - 他人とは手元では跳ね返さず、重ならないよう押し離すだけにする。跳ね返すとサーバーの結果と二重に弾かれる
- **他人は 80ms 遅れで、2つの状態の間を補間する。** サーバーの時計は「いちばん早く届いた状態」に合わせる。tick が巻き戻ったら(新しい部屋に移ったら)、時計ごと捨てる

### 出来事と接続

- **演出(衝突・脱落・決着)は、描く時刻に合わせて鳴らす。** 溜めた出来事は welcome で捨て、1 秒より古いものも捨てる。捨てないと2つのことが起きる
  - 裏のタブから戻ったとき、溜まった演出が一度に鳴る
  - 前の部屋の出来事が、新しい部屋の時刻で鳴る
- **接続は `setTimeout(0)` で1拍おいてから張る。** StrictMode は画面を作ってすぐ壊し、作り直す。1拍おかないと、張りかけの接続がもう1本できる(上の幽霊)
- **画面が読む依存は、開発サーバーの `optimizeDeps.include` に並べる。** 開発サーバーは初めて見た依存を事前バンドルし直し、ページごと読み込み直す。これも幽霊の元になる

### スマホの実機まわり

- **音は pointerdown だけでなく、pointerup・click・keydown でも解禁を試す。** iOS の Safari は pointerdown を利用者の操作に数えない
- **Wake Lock は start で取り、表に戻るたびに取り直す。** destroy のあとに解決した lock は release する
- **しこ名などの localStorage は `useSyncExternalStore` で読む**(サーバー側では null を返す)。サーバーで描かれうる部品が描画中に直接読むと、ハイドレーションで食い違う
- **canvas に 1px 未満のフォントを頼まない。** 盤面の単位(キャラの半径が 1)のまま文字を描くと、最小の文字サイズに丸めるブラウザがある。画面の px に戻してから描く
