# In Progress

まだ開発途中のスキル。出荷準備はできていない — 粗削りな部分、破壊的変更、放棄された実験を想定しておくこと。安定したバケットに昇格するまで、プラグインとトップレベルの README からは除外されている。

- **[loop-me](./loop-me/SKILL.md)** — 現在のディレクトリをステートフルな作業領域として使い、複数セッションにわたって自分自身をグリリングし、実装可能なワークフロー仕様に落とし込む。ユーザー呼び出し型。
- **[wizard](./wizard/SKILL.md)** — 人間が手作業の手順(セットアップ、一回限りの移行、状態遷移)を進める際に案内するインタラクティブな bash ウィザードを生成する — URL を開き、値を取得し、`.env` や GitHub Actions のシークレットを書き込む。ユーザー呼び出し型。
- **[writing-beats](./writing-beats/SKILL.md)** — 記事をビートの旅として、選択式アドベンチャー風に形作る。起点となるビートを選び、そのビートだけを書き、次に軸足を移す — 記事が自然な終わりを迎えるまで繰り返す。
- **[writing-fragments](./writing-fragments/SKILL.md)** — フラグメント(雑多な書き物の断片)を掘り出すグリリングセッションで、それらを1つのドキュメントに追記し、将来の記事のための素材にする。
- **[writing-shape](./writing-shape/SKILL.md)** — 素材のマークダウンファイルを受け取り、段落ごとに記事へと形作る。各ステップで書式の選択を議論する。
- **[claude-handoff](./claude-handoff/SKILL.md)** — 現在の会話を、`claude --bg` 経由の引き継ぎサマリーを種にした新規バックグラウンドエージェントに引き渡し、即座に作業を継続させる。ユーザー呼び出し型。
- **[setup-ts-deep-modules](./setup-ts-deep-modules/SKILL.md)** — TypeScript リポジトリに dependency-cruiser を組み込み、各パッケージを深いモジュールにする — 実装はサブフォルダに隠され、エントリーポイントのファイルを通じてのみ到達可能で、テストもそれらを通じて実行される。ユーザー呼び出し型。
- **[to-questionnaire](./to-questionnaire/SKILL.md)** — 自分だけでは答えきれない意思決定を、他の人が非同期に、あるいは打ち合わせの場で記入できるマークダウンのアンケートに変換する。対象について問い詰めるのではなく、送付内容(誰宛てか、何を得たいか)について問い詰める。ユーザー呼び出し型。
- **[batch-grill-me](./batch-grill-me/SKILL.md)** — 一問一答ではなく、設計ツリーをラウンド単位で進めていく容赦のないインタビュー — 各ラウンドで前提条件がすでに整った意思決定のフロンティア全体を問い、回答から再計算する。ユーザー呼び出し型。
