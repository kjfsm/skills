# 設定

## astro.config.mjs

EmDashサイトはCloudflare(D1 + R2 + KVキャッシュ)にデプロイする。`database`(D1)・
`storage`(R2)・`objectCache`(KV)・`plugins` を `emdash()` に渡す。

```javascript
import cloudflare from "@astrojs/cloudflare";
import react from "@astrojs/react";
import { d1, kvCache, r2 } from "@emdash-cms/cloudflare";
import { defineConfig } from "astro/config";
import emdash from "emdash/astro";

export default defineConfig({
  output: "server",
  adapter: cloudflare(),
  image: {
    layout: "constrained",
    responsiveStyles: true,
  },
  integrations: [
    react(),
    emdash({
      database: d1({ binding: "DB", session: "auto" }),
      storage: r2({ binding: "MEDIA" }),
      objectCache: kvCache({ binding: "CACHE" }),
      plugins: [],
    }),
  ],
  devToolbar: { enabled: false },
});
```

> EmDashはNode.js(`@astrojs/node` + `sqlite`/`local` ストレージ)やリバースプロキシ配下の
> セルフホストにも対応するが、これらのサイトはCloudflare専用。他アダプタの構成は
> `search_docs` を参照。

プラグインは`plugins`配列で登録する。作り方は `creating-plugins` スキルを参照。

D1・R2・KVのバインディングを含む`wrangler.jsonc`が必要。

```jsonc
{
  "name": "my-site",
  "compatibility_date": "2026-02-24",
  "compatibility_flags": ["nodejs_compat"],
  "assets": { "directory": "./dist" },
  "d1_databases": [{ "binding": "DB", "database_name": "my-site-db" }],
  "r2_buckets": [{ "binding": "MEDIA", "bucket_name": "my-site-media" }],
  "kv_namespaces": [{ "binding": "CACHE", "id": "<kv-namespace-id>" }],
}
```

## live.config.ts

すべてのEmDashサイトには、`src/live.config.ts`にこのファイルが必要です。これは定型コードで、どのプロジェクトでも同じです。

```typescript
import { defineLiveCollection } from "astro:content";
import { emdashLoader } from "emdash/runtime";

export const collections = {
  _emdash: defineLiveCollection({ loader: emdashLoader() }),
};
```

これによりEmDashのライブコンテンツコレクションがAstroに登録されます。すべてのコンテンツタイプは単一の`_emdash`コレクションを通じて配信されます -- `getEmDashCollection("posts")`などで特定のタイプをクエリします。

## emdash-env.d.ts

EmDashインテグレーションが**devサーバー起動時に**プロジェクトルートへ自動生成する
(ファイル冒頭に `// Generated by EmDash on dev server start` と入る)。コレクションごとの
TypeScript型を提供し、`tsconfig.json`がincludeする。スキーマが変わると自動で再生成される。

各エントリには、コレクション固有のフィールドに加えて、事前ロードされる `bylines`(著者
クレジットの配列)と `terms`(タクソノミー名 → 用語配列のレコード)が付く。

```typescript
// Generated by EmDash on dev server start
/// <reference types="emdash/locals" />

import type { ContentBylineCredit, TaxonomyTerm, PortableTextBlock } from "emdash";

export interface Blog {
  id: string;
  slug: string | null;
  status: string;
  title: string;
  featured_image?: { id: string; src?: string; alt?: string; width?: number; height?: number };
  summary?: string;
  content?: PortableTextBlock[];
  createdAt: Date;
  updatedAt: Date;
  publishedAt: Date | null;
  bylines?: ContentBylineCredit[];
  terms?: Record<string, TaxonomyTerm[]>;
}

declare module "emdash" {
  interface EmDashCollections {
    blog: Blog;
  }
}
```

## 型生成

`emdash-env.d.ts` は上記の通りintegrationがdevサーバー起動時に生成する。CLIの
`emdash types` でも生成できるが、**既定の出力先は `.emdash/types.ts`** なので、
`emdash-env.d.ts` を更新したい場合はdevサーバーを起動し直すのが手軽。

```bash
# スキーマから型を再生成(既定の出力先は .emdash/types.ts)
npx emdash types

# リモートインスタンスから
npx emdash types --url https://my-site.pages.dev

# 出力パスをカスタム指定
npx emdash types --output src/types/cms.ts
```

## devサーバー

```bash
npx emdash dev              # devサーバーを起動(マイグレーション実行、シード適用、型生成)
```

管理UIは`http://localhost:4321/_emdash/admin`にあります。初回実行時は、管理者アカウントを作成するセットアップを通過します。
