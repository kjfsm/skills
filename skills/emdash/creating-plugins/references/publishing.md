# マーケットプレイスへの公開

Sandboxedプラグインは、管理UIからのワンクリックインストールのためにEmDashマーケットプレイスに公開できる。

## バンドル形式

公開されたプラグインは`.tar.gz`アーカイブである。

| ファイル        | 必須 | 説明                                                    |
| --------------- | ---- | ------------------------------------------------------- |
| `manifest.json` | Yes  | `definePlugin()`から抽出されたメタデータ                |
| `backend.js`    | No   | バンドルされたsandboxコード（自己完結型のESモジュール） |
| `admin.js`      | No   | バンドルされた管理UIコード                              |
| `README.md`     | No   | プラグインのドキュメント                                |
| `icon.png`      | No   | プラグインアイコン（256x256 PNG）                       |
| `screenshots/`  | No   | 最大5枚のスクリーンショット（PNG/JPEG、最大1920x1080）  |

## バンドル用のパッケージエクスポート

bundleコマンドは、エントリポイントを見つけるために`package.json`のexportsを使う。

```json
{
  "exports": {
    ".": { "import": "./dist/index.mjs" },
    "./sandbox": { "import": "./dist/sandbox-entry.mjs" },
    "./admin": { "import": "./dist/admin.mjs" }
  }
}
```

| エクスポート  | 用途                                | ビルド方式                          |
| ------------- | ----------------------------------- | ----------------------------------- |
| `"."`         | メインエントリ — マニフェストを抽出 | external: `emdash`、`@emdash-cms/*` |
| `"./sandbox"` | sandbox用のバックエンドコード       | 完全に自己完結（externalなし）      |
| `"./admin"`   | 管理UIコンポーネント                | 完全に自己完結                      |

`"./sandbox"`が存在しない場合、コマンドは`src/sandbox-entry.ts`を探す。

## ビルドと公開

```bash
# バンドルのみ（先に中身を確認する）
emdash plugin bundle
tar tzf dist/my-plugin-1.0.0.tar.gz

# 公開（マーケットプレイスにアップロード）
emdash plugin publish

# ビルド + 公開を1ステップで
emdash plugin publish --build
```

初回の公開時にはGitHubのデバイス認可フローで認証する。トークンは`~/.config/emdash/auth.json`に保存される（有効期限30日）。

## バリデーション

bundleコマンドは以下をチェックする。

- **サイズ上限** — バンドル合計サイズが5MB未満であること
- **Node.js組み込みモジュール禁止** — `backend.js`は`fs`、`path`などをインポートできない
- **サンドボックス非互換機能** — プラグインが`portableTextBlocks`、`admin.entry`（Reactコンポーネント）、またはAPIの`routes`を宣言している場合は警告される。これらはtrustedモードを必要とするため
- **アイコンの寸法** — 256x256 PNG（違反時は警告）
- **スクリーンショットの上限** — 最大5枚、最大1920x1080

## セキュリティ監査

公開されたバージョンはすべて自動的に以下について監査される。

- データ流出パターン
- 設定経由の認証情報収集
- 難読化されたコード
- リソース悪用（クリプトマイニングなど）
- 不審なネットワーク活動

判定結果: **pass**、**warn**、または**fail** -- マーケットプレイスの掲載ページに表示される。

## バージョンに関する要件

- 各バージョンは直前のバージョンより高いsemverでなければならない
- 既存バージョンの上書きや再公開はできない
- プラグインIDは初回公開時に自動登録される
