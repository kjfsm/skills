# docs/product.md のひな形

写して埋める。各節は箇条書きで数行に収める — 長くなるのは、機能の一覧を書き始めた合図である。機能の一覧はコードが持っている。

```markdown
# <アプリ名>

## 誰が使うか

- <利用者の種類>: <その人の立場と、使う場面>

## 何のために使うか

- <利用者が片付けたいこと。機能名ではなく、利用者の言葉で>

## 何をしないか

- <やらないこと> — <理由>
```

「何をしないか」は、却下した提案の行き先でもある。行を足すときは理由を添える — 理由の無い行は、状況が変わったときに消してよいかを誰も判断できない。
