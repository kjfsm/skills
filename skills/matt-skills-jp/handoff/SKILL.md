# 引き継ぎ

新しいエージェントが作業を継続できるよう、今の会話を要約した引き継ぎドキュメントを書く。現在のワークスペースではなく、ユーザーの OS の一時ディレクトリに保存する。

ドキュメントには、エージェントが呼び出すべきスキルを提案する「おすすめのスキル」セクションを含める。

他の成果物(スペック、計画、ADR、イシュー、コミット、差分)にすでに記録されている内容を重複させない。代わりに、パスや URL で参照する。

API キー、パスワード、個人を特定できる情報など、機密情報はすべて伏せる。

ユーザーが引数を渡した場合は、それを次のセッションが何に焦点を当てるかの説明として扱い、それに合わせてドキュメントを調整する。
